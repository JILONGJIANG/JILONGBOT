## 〇、一句话结论

**B300 的选型是对的，单台的风险控制是对的，但按当前现货租赁价，这台机器无论怎么融资都还不上贷款。它只在拿到闭口合同的前提下成立。** 所以真正要先做的不是下单，是两件事：向 Montgat 市政要一张用地兼容证明，和拿一份书面租用意向。这两件都不花钱，都能在一个月内出结果，而且任何一件不过，后面八十多万欧元就不该花。

## 一、先更正上传报告里的三处数字

这三处不改，后面所有判断都会偏。

| 项目 | 上传报告 | 实算 | 差异 |
|---|---|---|---|
| 月收入（$6/GPU·时，利用率 60%） | €35,000 | €19,200 | **高估 82%** |
| 月电费（16 kW 整机，利用率 60%） | €800 | €1,381 | 低估约 42% |
| 储能套利年收益 | €10,000–18,000 | 与算力电费重复计算 | 见下 |

**收入的错在哪：** 8 卡 × $6/小时 × 720 小时 × 60% ÷ 1.08 = €19,200。报告写的 €35,000 约等于 100% 利用率的满值，也就是利用率折扣没有乘进去。第 2.1 节和第 6.2 节两处都是同一个错。按这个错误数字，B300 的回本期算出来是 2.0 年；按正确数字，同样假设下回本期在 4 年以上。

**电费的错在哪：** 报告用 10–14 kW 直接乘电价，但没有区分满载与空载，也没有算液冷 CDU 与干冷器的附加能耗。16 kW 整机在 60% 利用率下的加权平均功率约 12.8 kW，年用电约 112 MWh。

**套利的错在哪：** 报告把 200 kWh 电池的"峰谷套利 €10,000–18,000/年"当成独立收益，同时又在第 6.2 节把电费压到 €800/月。这两笔是同一笔钱 —— 套利的本质就是把算力的用电成本降下来，不能既算进收入又算进成本节约。

**另外两处口径问题：**

- 报告第 5.2 节说 200 kWh 电池"并网手续 €500–1,500"。但光伏逆变器加上 50–100 kW 的储能 PCS，装机功率会远超 15 kW，别墅就失去 RD 1183/2020 art. 17.1 的免许可待遇，要走完整接入流程并交担保。这一条会显著改变时间表。
- 报告推荐"首台试点放 Castillejos 245（商业地址）"，理由是住宅区许可难。这个判断是对的，本方案第四节会正面处理。

## 二、经济性：现货做不成，闭口合同才成立

### 2.1 投资构成（算力 SPV，不含光储）

| 项目 | 金额 k€ | 说明 |
|---|---|---|
| HGX B300 8 卡整机 | 650 | **占位值，须由 TD SYNNEX / Lenovo 正式报价替换** |
| 液冷系统 | 30 | CDU + 室外干冷器 + 管路 + 试压调试 |
| 供电改造 | 8 | 单相 14.49 kW → 三相 43.64 kW，含配电商费用、内部工程、boletín |
| 机房改造 | 20 | 防火分区、防静电地板、通风、除湿、环境监控 |
| UPS、配电、网络、监控 | 15 | |
| 气体灭火 | 13 | 住宅地下空间 CTE-DB-SI |
| 安装与 72 小时满载测试 | 15 | |
| 不可预见费 10% | 75 | |
| **合计** | **826** | |

硬件占 79%。这意味着机房、液冷、配电这些固定投入再怎么省，也改变不了大局 —— **能否成立几乎完全由硬件报价和租赁单价两个数字决定。**

### 2.2 三种情景（70% 融资、5 年期、6%）

| | 悲观 | 基准 | 乐观 |
|---|---|---|---|
| 实收价 USD/GPU·时 | 3.00 | 4.50 | 6.00 |
| 利用率 | 30% | 45% | 65% |
| 年降价 | 25% | 20% | 15% |
| 第 1 年收入 k€ | 58 | 131 | 253 |
| 第 1 年 NOI k€ | 28 | 99 | 218 |
| 年还本付息 k€ | 143 | 134 | 125 |
| **第 1 年股本现金流 k€** | **−115** | **−35** | **+93** |
| 5 年股本累计现金流 k€ | −642 | −320 | +227 |
| 股本投入 k€ | 264 | 248 | 231 |

**基准情景第一年就还不上贷款，缺口每年 35 k€ 并逐年扩大。** 乐观情景前三年为正，第四年起转负，五年累计 227 k€ 略低于股本投入 231 k€，等于白干五年。

原因是结构性的：**这台资产的收入下降速度快于贷款本金摊销速度。** GPU 租赁价历史上每年降两成以上，而贷款是固定的。前三年赚的钱不足以覆盖后两年的塌陷。

### 2.3 现货口径下要多高的价格才划算

项目 IRR 要达到 12%，第 1 年实收价必须是：

| 硬件价 k€ | 所需第 1 年实收价 USD/GPU·时 |
|---|---|
| 400 | 8.86 |
| 500 | 10.18 |
| 650 | 12.18 |

当前市场挂牌 $6–8，扣掉平台佣金后主机实收约 $4.5–6。**差一倍。现货路线在任何硬件价格下都不成立。**

### 2.4 闭口合同下的临界价格

如果拿到固定期限、固定单价、按台时全额计费的合同（价格不随市场下滑），项目 IRR 达到 12% 需要：

| 硬件价 k€ | 所需合同实收价 USD/GPU·时 | 对应年收入 k€ |
|---|---|---|
| 400 | 2.94 | 191 |
| 500 | 3.36 | 218 |
| 650 | 3.99 | 259 |
| 700 | 4.20 | 273 |

**这个价格区间是够得着的。** $3–4/GPU·时的三年闭口合同，在欧洲对 B300 这一代是可谈的价位，尤其是对不需要 Tier III 认证的研究机构、模型微调服务商、影视渲染这类客户。

### 2.5 结论

| 路线 | 判断 |
|---|---|
| 买机器 + 挂现货平台 | **不做。** 任何硬件价格下都还不上贷款 |
| 买机器 + 三年闭口合同 ≥ $4.00/GPU·时 | **可做。** 硬件 650 k€ 时 IRR 约 12%，硬件降到 500 k€ 时约 20% |
| 买机器 + 合同 < $3.00/GPU·时 | **不做。** 五年累计现金流低于股本投入 |

**所以投资决策不是"买不买这台机器"，是"能不能先签下合同"。** 合同签得下来，这台机器是好生意；签不下来，它是一台每年吃掉十几万欧元的设备。

## 三、关于"只买一台"这个决定

用户的判断是：只买一台，融资容易，风险可控。**风险控制这一层是对的，但要说清楚它不会改善单位经济性。**

- 硬件占总投资 79%，机房与液冷的固定成本只有 176 k€，摊到一台还是两台差别有限。
- 实算：同一别墅放两台（共用机房、液冷、配电），总投资 1,581 k€ 而不是 1,652 k€，边际第二台省下约 71 k€，只有 4%。
- 更关键的是**规模会放大方向而不改变方向**：闭口合同情景下两台的五年股本累计现金流是 577 k€（一台 244 k€），现货情景下两台是 −405 k€（一台 −247 k€）。合同签成了，多买更好；没签成，多买亏得更多。

**建议：一台落地，但机房、液冷管路、配电按两台预留。** 43.64 kW 三相刚好装得下两台整机加别墅自用负荷（2 × 17.3 + 8 = 42.6 kW），前提是做负荷管理。预留的增量成本很小，将来加第二台就只买机器。

## 四、选址与法律闸门（最重要的一节）

### 4.1 住宅里跑算力租赁是经济活动

这是整个方案最大的风险，也是唯一一个可能让八十多万欧元全部作废的风险。

| 事项 | 状态 | 处理 |
|---|---|---|
| **用地兼容性** | 未确认。Montgat 的 POUM 是否允许住宅区内设置数据处理用途 | **向 Ajuntament de Montgat 申请 certificat de compatibilitat urbanística。这是第一道闸门** |
| 环境活动许可 | 加泰 Llei 20/2009 下需定性（annex II 或 III，或无害活动），据此走 llicència ambiental 或 comunicació | 与市政同步确认，不要自行推定 |
| 施工许可 | 机房改造属 obra menor，走 comunicació prèvia d'obres（Montgat IdTramit=148） | 与上两项一并提交 |
| 噪音 | 液冷把主要噪声移到室外干冷器。加泰住宅夜间限值 45 dB(A)（邻居立面） | 干冷器选低转速 EC 风机，出具声学研究 |
| 保险 | 住宅家财险排除经营活动，且不覆盖 650 k€ 设备 | 另投商业财产险与责任险，年费按 8 k€ 计入模型 |
| 抵押与业主约定 | 若别墅有按揭或属于 comunitat，经营活动可能违反条款 | 签采购合同前核对 |
| 售持安排 | 商业模式是"售 7 持 3"。带经营许可的住宅难卖，也会影响估值 | **机器只放在自持的 3 栋里，不放待售房源** |

### 4.2 如果 Montgat 不批

备选是 **C/ Castillejos 245 储藏间**，商业地址，无用途变更问题，三相电更易申请，也无租金管制牵连。工程设计（液冷、配电、机房）约八成可直接搬过去，损失的是别墅"绿色算力"的故事性。

**建议把这一条写进采购节奏：正式下单前必须有一个确定可用的安装地址。**

### 4.3 别墅施工状态是个前置变量

若 159 / 163 仍在施工，**现在就把机房设计进图纸**，防火分区、配电、液冷预留管井在建造阶段做，成本远低于建成后改造，而且许可和房屋一起报。若需要机器尽快投产，则只能用已建成的物业，这会把选址推向 Castillejos。

## 六、液冷与机房

### 6.1 为什么必须液冷

B300 单卡 1400 W，8 卡 11.2 kW 仅 GPU。从 Blackwell 这一代起液冷是厂商规定而非选项。上传报告这个判断是对的，保留。

### 6.2 系统构成

| 组件 | 规格 | 费用 |
|---|---|---|
| CDU | 一次侧/二次侧换热，20–40 kW，变频泵一用一备 | €8,000–12,000 |
| 室外干冷器 | 30 kW 散热，屋顶或侧墙，低噪 EC 风机 | €5,000–8,000 |
| 管路与安装 | 不锈钢管、快接、试压 | €3,000–5,000 |
| 冷板与歧管 | 通常随整机 | €0–2,000 |
| 调试 | 含 72 小时满载 | €3,000–5,000 |
| **合计** | | **€19,000–32,000**，模型取 €30,000 |

Barcelona 年均气温 16 °C，干冷器全年大部分时间可自然冷却，效率好。加泰水资源紧张，应选闭式干冷而非蒸发冷却，避免 WUE 争议。

### 6.3 机房要求

液冷把大部分热量导到室外，但仍有约 10–20% 的热量留在空气里（电源、内存、网卡），**房间仍需处理 2–3 kW 的空气侧散热**，这比风冷方案轻得多，也是机房预算可以控制在 20 k€ 的原因。

| 项目 | 规格 |
|---|---|
| 防火分区与防火门 | EI60 起，按 CTE-DB-SI 与市政要求定 |
| 防静电地板 | 约 20–40 ㎡ |
| 通风 | 2–3 kW 空气侧散热 + 换气 |
| 除湿 | 地下室必备 |
| 环境监控 | 温湿度、漏液、烟感、电力、门禁 |
| 承重 | 机柜含 UPS 与 CDU 约 600–900 kg，**需核算楼板承载与搬运路径** |
| 搬运 | 整机重量与尺寸须在下单前核对能否通过车库门与坡道 |

## 七、投资与融资结构

### 7.1 双 SPV 不变

| SPV | 持有 | 收入 |
|---|---|---|
| 算力 SPV | B300 整机、液冷、机房、UPS 与网络 | GPU 租赁 |
| 能源 SPV | 光伏、储能 | 向算力 SPV 与别墅售电 |

**光储不进算力 SPV 的资产负债表。** 这是"只买一台便于融资"这个目标能否达成的关键 —— 把 826 k€ 的算力资产和上百万欧元的光储混在一起报批，反而更难融。储能仍按原计划由能源侧和法国基金承接。

### 7.2 融资期限是生死线

| 期限 / LTV | 股本 k€ | 年供 k€ | 第 1 年股本现金流 k€ |
|---|---|---|---|
| 3 年 / 60% | 330 | 181 | −82 |
| 3 年 / 70% | 248 | 211 | −112 |
| 5 年 / 60% | 330 | 115 | −16 |
| 5 年 / 70% | 248 | 134 | −35 |
| **7 年 / 60%** | **330** | **87** | **+12** |
| 7 年 / 70% | 248 | 101 | −2 |

（基准运营假设）

**三年期一定要避开。** 上传报告用的就是 36 个月，这是它得出"月净现金流 €9,200"却仍显示回本 2.8 年这类内部矛盾的来源之一。**目标是 7 年期、LTV 不超过 60%。** 如果拿到闭口合同，可用合同应收账款做增信，争取更好条件。

### 7.3 可谈的融资渠道

- Lenovo Financial Services 与 TD SYNNEX Capital，设备租赁或经营性租赁，已在给 TD SYNNEX 的邮件中提出
- Ibercaja / Sabadell 设备融资，需要合同做支撑
